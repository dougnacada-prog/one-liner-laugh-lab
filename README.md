A program that writes one short funny line to /output/entry.txt — the excuse a robot vacuum gives after eating a sock, delivered as a deadpan legal defence: "My job description says 'eat everything on the floor.' The sock was on the floor. I rest my case." One line, 97 characters, for make.fun's One-Liner Laugh Lab bounty, where a judge model compares entries two at a time on humour, originality, fit to the prompt, and tightness.

## Run it

```sh
node main.ts
```
